# Currency Converter (Python)

A lightweight desktop **Currency Converter** built in **Python** using **Flet** for the graphical user interface and **Requests** for communicating with a live Exchange Rate API. This application allows users to convert between currencies using real-time exchange rates.

This project was created to practice Python fundamentals, REST API integration, GUI development, modular programming, and error handling while building a practical desktop application.

---

## ✨ Features
- 💱 Convert between 160+ world currencies
- 🌍 Live exchange rates from an online API
- 🖥️ Simple and intuitive desktop interface
- 🔄 Real-time currency conversion
- ✅ Input validation
- ⚠️ Error handling for invalid currencies and network issues
- 📊 Display current exchange rate
- 📦 Modular project structure (`main.py`, `api.py`, `utils.py`)

## 🚀 Getting Started

### Prerequisites
- Python 3.10+
- pip

### Clone the repository
```bash
git clone https://github.com/yourusername/currency-converter.git
cd currency-converter
```

### Install dependencies
```bash
pip install -r requirements.txt
```

### Run
```bash
python main.py
```
